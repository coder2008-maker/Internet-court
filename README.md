# The Internet Court ⚖️

A playful, frontend-only arcade courtroom project built with HTML, CSS, and vanilla JavaScript.

## Run
Open `index.html` in a modern browser.

## Controls
- WASD / Arrow keys — move
- Mouse click / Space — shoot
- Collect ⚡ 🛡️ ⭐ power-ups

## Includes
- Friendly viby UI
- Funny courtroom backgrounds
- Crime + severity system
- Interactive evidence
- Random judgements
- Judge boss fight
- Supreme Judge final phase
- Power-ups, HP, accuracy, XP
- Achievements
- Local case history
- Responsive design
